This repository contains the deliverables for three Agile/Scrum case studies. Each case study folder contains one consolidated documentation file, structured backlog data, and a folder for Jira screenshots.

## Folder structure

Each case study contains:
- `README.md` – quick overview and Jira link.
- `case_study.md` – all written analysis in one place.
- `backlog.csv` and `backlog.xlsx` – structured backlog data.
- `screenshots/` – add your Jira evidence screenshots here.
