## Repository structure

Each project folder contains:
- `README.md` – project overview and Jira reference.
- `case_study.md` – all written work consolidated into one document.
- CSV backlog data.
- Supporting visual, where applicable.
- `screenshots/` – Jira screenshots captured for the project.
