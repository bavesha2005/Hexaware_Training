# Screenshots – Airline Web Check-in

Add your Jira screenshots to this folder.

Suggested evidence:
- Board and sprint backlog
- Sprint details and Sprint Goal
- Relevant epics, stories, tasks, and impediment issues
- Any scope-change or sprint-planning views

Use descriptive filenames, for example:
- `01-board.png`
- `02-sprint-backlog.png`
- `03-epics-and-stories.png`
- `04-impediment.png`

The screenshots are not included in this package; add the screenshots you captured.
