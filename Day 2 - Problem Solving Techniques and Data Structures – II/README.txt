DAY 2 – PROBLEM SOLVING TECHNIQUES AND DATA STRUCTURES – II
================================================================

This repository contains three practical problem-solving sets implemented in Python.

FOLDER STRUCTURE
----------------
Set 1 - E-Commerce Catalogue and Traffic Analysis/
    README.txt
    ecommerce_catalogue.py
    execution_output.txt
    decision_table.md

Set 2 - Insurance Claims Processing/
    README.txt
    insurance_claims.py
    execution_output.txt
    test_cases.py
    complexity_table.md

Set 3 - Logistics Network and Delivery Windows/
    README.txt
    logistics_network.py
    execution_output.txt
    algorithm_explanations.md

REQUIREMENTS
------------
- Python 3.9 or later
- No third-party packages are required.

RUNNING THE PROJECT
-------------------
Open a terminal in the relevant set folder and run:

    python ecommerce_catalogue.py
    python insurance_claims.py
    python test_cases.py
    python logistics_network.py

The execution_output.txt files contain sample output from running the programs.
Run the scripts locally to reproduce the output.

TOPICS COVERED
--------------
- Binary Search Trees and tree traversals
- Hash tables, collision handling and Python dictionaries
- Graphs, BFS, DFS and cycle detection
- Sliding-window algorithms
- Two-pointer techniques
- Time and space complexity analysis
